# Safestrap

**Safe multi-platform Roblox bootstrapper** built with Flutter, C# and Luau.

## Goals
- Clean & secure launcher for Roblox
- Runs on Android, iOS, Windows, Linux, and macOS
- Safe FastFlag support
- Modern dark UI
- Luau scripting hooks
